# Lucas Frery — E-Portfolio Website Notes

## Project objective

Build a professional e-portfolio website for job applications, focused on hardware electronics, embedded systems, PCB design, STM32 development, automotive systems, robotics, and engineering case studies.

The website should present each experience in detail with:

1. Context
2. My role
3. Plan
4. Implementation
5. Results
6. Conclusion

The design direction should feel like an electronics engineer portfolio: modern, technical, dark, clean, precise, with possible visual references to PCB traces, signals, embedded systems, and control units.

---

## Technical stack selected

The selected stack is:

- Next.js
- React
- TypeScript
- Tailwind CSS
- App Router
- npm
- VS Code
- GitHub later
- Vercel later for deployment

Optional future tools:

- Motion for React for smooth animations
- GSAP only if advanced scroll animations are really needed
- MDX later if project case studies become long-form technical articles
